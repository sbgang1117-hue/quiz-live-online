# QUIZ LIVE v7.0.0

v6.6.0을 기반으로 한 대형 기능 패치입니다.

## v7 패치노트

### 새로 구현
- **배경 이미지 직접 업로드**: URL 입력 대신 JPG/PNG/WebP/GIF 파일을 선택해 서버에 업로드합니다. 최대 5MB.
- **문제 이미지도 서버 업로드 방식으로 통일**: 기존 Base64 방식 대신 `/uploads` 파일 URL을 사용합니다. 기존 Base64 이미지가 남아 있으면 조회 시 자동 마이그레이션합니다.
- **문제 편집 편의성 강화**
  - 문제 위/아래 이동
  - 문제 복제
  - 마지막 문제 삭제 방지
- **JSON 백업/복원**
  - 현재 퀴즈 JSON 내보내기
  - JSON 파일 불러오기
  - 가져온 퀴즈는 새 퀴즈로 저장할 수 있습니다.
- **대기실 QR 코드**: 서버에서 QR SVG를 생성해 방 입장 링크를 바로 스캔할 수 있습니다.
- **호스트 문제 건너뛰기**: 진행 중인 문제를 즉시 정답 공개로 넘기거나 공개/다음 문제 단계에서 다음 문제로 이동할 수 있습니다.
- **최종 통계**
  - 참가자별 정답 수
  - 정확도
  - 평균 응답 시간
  - 문제별 응답 기록
- **테마 배경 실제 적용**: 저장한 배경 이미지가 라이브 게임/공개 화면에 적용됩니다.
- **기존 기능 유지**: 음악 파일 서버 업로드, 20MB 제한, 멀티유저 음악 퀴즈, YouTube 구간 재생, O/X/주관식/복수선택/순서맞추기, 아바타, FEVER/PLATINUM, 점수 공개 타이밍, 재접속 토큰 등을 유지합니다.

## 안정성 점검
- `server.js` Node 문법 검사 통과
- `public/app.js` Node 문법 검사 통과
- v6.6의 Socket.IO 2MB 제한은 그대로 유지해 대용량 미디어가 WebSocket으로 다시 흘러들어가는 문제를 방지합니다.
- 이미지/음악은 HTTP multipart 업로드 후 URL만 실시간 퀴즈 데이터에 저장합니다.
- 재접속 참가자의 과거 통계를 유지하도록 통계 식별자는 소켓 ID가 아닌 재접속 토큰을 사용합니다.

## 실행
```bash
npm install
npm start
```

Postgres를 사용하려면 `DATABASE_URL`을 설정합니다. 설정하지 않으면 `data/quizzes.json`을 사용합니다.

> 주의: 현재 `/uploads`는 서버 로컬 파일 저장 방식입니다. 호스팅 환경에서 재배포/재시작 시 파일이 초기화되는 서비스라면 추후 S3/R2/Supabase Storage/Cloudinary 같은 영구 스토리지로 교체하는 것이 좋습니다.
